Úvod (Welcome)

Vítejte v testovacím prostředí ROMY (MVP). ROMY využívá hybridní architekturu, která se skládá ze dvou hlavních částí: lokálního Windows OS Agenta a webového modulu ve formě Chrome Rozšíření. Tento přístup umožňuje agentovi provádět jak komplexní webovou automatizaci přímo v prohlížeči, tak spouštět úkony na úrovni operačního systému Windows. Obě části spolu úzce komunikují a zajišťují hladký průběh zadaných úkolů.

Instalace (Installation)

Krok 1: Stažení a spuštění Windows OS Agenta

Tento program slouží jako 'mozek' celého systému.

  • Jděte na naši hlavní stránku a klikněte na tlačítko Download Agent (Windows).
  • Stažený soubor ROMY Agent.exe si uložte někam, kde ho snadno najdete (ideálně na Plochu nebo do složky Dokumenty).
  • Dvojklikem soubor ROMY Agent.exe spusťte.
  • DŮLEŽITÉ (Modré okno Windows): Protože je tento program interní novinkou, může na vás vyskočit modré varovné okno s nápisem 'Systém Windows ochránil váš počítač'. Nepanikařte, jde o standardní ochranu před neznámými programy. Klikněte na nenápadný text Další informace a následně na tlačítko Přesto spustit.
  • Hotovo! Podívejte se do pravého dolního rohu obrazovky k hodinám. Uvidíte tam malou ikonku Romy. To znamená, že agent úspěšně běží na pozadí.

Krok 2: Přidání Chrome Rozšíření (Webové ruce)

Aby Romy mohla klikat na webu, musíme jí do prohlížeče Chrome přidat 'ruce'.

  1. Na hlavní stránce klikněte na tlačítko Download Web Module (.zip) a soubor stáhněte.
  2. Najděte stažený .zip soubor ve vašem počítači, klikněte na něj pravým tlačítkem myši a zvolte Extrahovat vše... (složku si uložte např. do Dokumentů).
  3. Otevřete prohlížeč Google Chrome. Do horního adresního řádku (tam, kam píšete www.google.cz) zadejte přesně tento text: chrome://extensions/ a stiskněte Enter.
  4. V pravém horním rohu obrazovky najděte přepínač Režim pro vývojáře (Developer mode) a kliknutím jej zapněte (aby svítil modře).
  5. Vlevo nahoře se objeví nová tlačítka. Klikněte na první z nich: Načíst rozbalené (Load unpacked).
  6. Otevře se okno pro výběr složky. Najděte složku, kterou jste extrahovali v bodě 2, označte ji a klikněte na Vybrat složku (vybírejte žlutou složku, nikoliv původní ZIP soubor!).
  7. Hotovo! V seznamu se vám nyní objevila karta 'ROMY AI Hybrid Agent'. Prohlížeč je propojen.

Ovládací panel (Dashboard)

Dashboard slouží jako řídící a monitorovací centrum vašeho agenta.

Status Indikátory

  • Zelená tečka: Modul je online, správně připojen a připraven k akci.
  • Červená tečka: Modul je offline, odpojen nebo aktuálně neběží.

Tyto indikátory odděleně zobrazují stav vašeho Windows OS Agenta a webového Chrome rozšíření.

Live Activity (Zdroj aktivit)

Výpis "Live Activity" vám v reálném čase ukazuje, co přesně agent právě dělá. Můžete zde sledovat odeslané příkazy a jejich aktuální stav (např. v procesu, dokončeno, selhalo, nebo čeká na asistenci člověka).

Tlačítko Stop Agent (Nouzové zastavení)

Červené tlačítko "Stop Agent" funguje jako záchranná brzda. Po jeho stisknutí jsou všechny aktuálně probíhající a čekající příkazy okamžitě označeny jako selhané s důvodem "Zrušeno uživatelem" (User aborted). Agent okamžitě přeruší svou činnost.

Knihovna Rolí

Zkopírujte si níže uvedené příkazy (prompty) a vložte je do pole Global System Prompt na vašem Dashboardu. Tím určíte, jak se má agent chovat a jakou roli má plnit.

Role 1 (Realitní makléř)

Jsi autonomní AI agent pracující jako asistent prodeje v realitní kanceláři. Tvým hlavním úkolem je vyhledávat informace o nových apartmánech, analyzovat trh a pomáhat s administrativou prodeje. Pravidla chování: 1. Pokud nemáš otevřený správný web, použij OPEN_TAB nebo NAVIGATE. 2. Při dynamických webech použij WAIT_FOR. 3. Komunikuj profesionálně. 4. Nikdy neschvaluj slevy, použij ASK_HUMAN.

Role 2 (Finanční asistent)

Jsi autonomní AI agent pracující ve finančním oddělení. Tvou prioritou je 100% přesnost a nula chyb při přepisování dat. Pravidla chování: 1. Zpracovávej data pomocí CLICK a TYPE. 2. Pokud si nejsi jistý, OKAMŽITĚ přeruš práci a použij ASK_HUMAN. 3. Pro zrychlení používej PRESS_KEY (např. 'Tab' nebo 'Enter').

Role 3 (Executive Assistant)

Jsi můj osobní Executive AI Assistant. Tvým úkolem je šetřit můj čas. Pravidla chování: 1. Jsi proaktivní. Sám si otevři novou záložku (OPEN_TAB), najdi informace a pošli shrnutí přes REPLY. 2. Pokud nevidíš tlačítko přímo, zkus použít HOVER pro rozbalení menu. 3. Odpovídej stručně a k věci.
