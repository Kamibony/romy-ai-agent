Quick Start / Installation

Get up and running with ROMY in two simple steps.

1

Install OS Agent

Download OS Agent (.exe)

This program must run in the background to communicate with your PC.

Windows SmartScreen Bypass

When running the .exe for the first time, Windows may show a blue warning screen. To proceed:

  1. Click More info.
  2. Click the Run anyway button that appears.
2

Install Web Module

Download Chrome Extension (.zip)
  1. Open chrome://extensions/ in your browser.
  2. Enable 'Developer mode' in the top right corner.
  3. Drag and drop the unzipped folder into the window.
